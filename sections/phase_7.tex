\section{Fase 7, Sincronización Nocturna con Google Drive}

\textbf{Objetivo:} Verificar que el script de sincronización sube correctamente los archivos a Google Drive y los elimina localmente, y que ante un fallo de red los archivos quedan intactos en la Raspberry Pi.

% --- TEST 18 ---
\subsection{T-18, Sincronización manual: subida y borrado local}

Cree un archivo de prueba (no utilice archivos de evento reales) y ejecute el script de sincronización:

\begin{lstlisting}[language=bash]
echo "test" > /home/kraken/Signal-Recorder/events/test_dummy.iq
bash /home/kraken/Signal-Recorder/sync_events.sh
\end{lstlisting}

\begin{tcolorbox}[colback=gray!5, colframe=deyposcolor, title=Resultado esperado (T-18)]
\begin{itemize}
    \item Ningún error de \texttt{rclone} en el terminal.
    \item \texttt{test\_dummy.iq} \textbf{ya no existe} en el directorio local \texttt{events/}.
    \item En Google Drive, el archivo es visible bajo la ruta \texttt{Kraken/<fecha de hoy>/}.
\end{itemize}
\end{tcolorbox}

\begin{important}
    \textbf{Si los archivos no se eliminan localmente:} El remoto \texttt{rclone} puede no estar configurado o tener un nombre incorrecto. Ejecute \texttt{rclone config} y confirme que el remoto se llama exactamente \texttt{gdrive} (sensible a mayúsculas).
\end{important}

% --- TEST 19 ---
\subsection{T-19, Fallo de sincronización preserva los archivos locales}

Simule un fallo de red apuntando \texttt{rclone} a un remoto inexistente:

\begin{lstlisting}[language=bash]
SOURCE="/home/kraken/Signal-Recorder/events/"
echo "dummy" > "$SOURCE/keep_me.iq"

# Simula el fallo con un nombre de remoto inexistente
rclone copy "$SOURCE" "nonexistent_remote:test/" --include "*.iq"
# El codigo de salida ($?) debe ser distinto de 0

ls "$SOURCE"
\end{lstlisting}

\begin{tcolorbox}[colback=gray!5, colframe=deyposcolor, title=Resultado esperado (T-19)]
\texttt{keep\_me.iq} \textbf{sigue presente} en el directorio local tras el fallo de \texttt{rclone}. El script de sincronización no debe eliminar archivos locales si la transferencia no se completa con éxito.
\end{tcolorbox}

Limpie el archivo de prueba antes de continuar con las siguientes fases:

\begin{lstlisting}[language=bash]
rm /home/kraken/Signal-Recorder/events/keep_me.iq
\end{lstlisting}
