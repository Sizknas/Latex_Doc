\section{Introducción}
 Este documento, el Acceptance Test Report contiene las pruebas que se realizarán para validar el funcionamiento del prototipo de KRAKEN. Estas pruebas tiene como objetivo validar el funcionamiento del prototipo, en este caso la detección de señales de Inmarsat e Iridium, de señales de frecuencia central de 1641.5~Mhz y 1621.3~MHz respectivamente. Estas frecuencias corresponden a señales tierra-espacio con informacion de la posicion de las radio balizas.

 Las pruebas validarán el uso por separado tanto del Hardware como del Software, asi como la deteccion de las boyas de SATLINK y ZuniBal disponibles. Es importante recalcar que no se mandarán señales ad-hoc como el uso del flash, ya que las boyas en mar abierto unicamente transmite señales de posición cada hora o cada ocho horas. Otras señales son muy escasas y su detección es practicamente imposible.

\subsection{Alcance y Notación}

El presente ATP cubre las siguientes fases de validación:

\begin{itemize}
    \item \textbf{Fase 0, Pre-test:} Verificación física del hardware y la conectividad.
    \item \textbf{Fases 1–2:} Validación de hardware RTL-SDR y suite de tests unitarios de software.
    \item \textbf{Fase 3:} Verificación de recepción RF en ambas frecuencias objetivo.
    \item \textbf{Fases 4–5:} Detección de eventos, grabación y verificación de integridad de archivos IQ.
    \item \textbf{Fase 6:} Persistencia del servicio \texttt{systemd} ante reinicios y fallos.
    \item \textbf{Fase 7:} Sincronización automática con Google Drive.
    \item \textbf{Fase 8:} Prueba de resistencia extendida (opcional).
\end{itemize}
